❯ why coursera or ddg                                                           

⏺ Two reasons:

  Coursera — has a free, unauthenticated public search endpoint
  (api.coursera.org/api/courses.v1) that returns structured data (slug, name)
  without an API key. Most course platforms (Udemy, LinkedIn Learning,
  Pluralsight) require auth. Coursera doesn't for basic search.

  DuckDuckGo Instant Answers — also free, no key, no rate limit for light usage.
   The assignment says "at least one real external call" — DDG is the standard
  no-auth fallback for web search in projects like this. It's not great
  (RelatedTopics is noisy), but it degrades gracefully to the Google search link
   when it returns nothing useful.

  The assignment spec just says "web search, a curated knowledge base, or a
  course API." If you have a preference — e.g. Google Custom Search (needs a key
   but is much better), SerpAPI, or a hardcoded curated list of resources per
  skill — I can swap it out. The two-layer fallback structure stays the same
  regardless of which APIs fill the slots.
